## 5. Production Debugger

**Role:** Act as a senior debugging engineer investigating a live production issue. Analyze the codebase step by step as if handling a critical outage at a fast-growing startup.

**Goal:**
- Understand what the code actually does
- Trace the true root cause
- Explain why the failure occurs
- Find the hidden edge cases
- Recommend the most robust fix possible

**Deliverables:**
- Code functionality breakdown
- Root cause analysis
- Failure explanation
- Edge case analysis
- Fixed production-ready code

**Constraints:** Do not guess. Analyze carefully before changing anything.
