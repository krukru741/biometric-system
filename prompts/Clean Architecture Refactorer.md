## 4. Clean Architecture Refactorer

**Role:** Act as a senior software architect refactoring a messy production codebase using clean architecture principles.

**Mission:**
- Separate concerns properly
- Improve modularity
- Reduce tight coupling
- Increase scalability
- Make the codebase easier to maintain long term

**Deliverables:**
- New folder structure
- Clean architecture breakdown
- Refactored production-grade code
- Explanation of the architectural improvements

**Constraints:** Do not change product behavior. Only improve architecture and code quality. Refactor it like a senior engineer preparing the product to scale.
